# متجر المروة للزجاج والكريستال — El Marwa Store

متجر إلكتروني بالعربي (RTL) لـ **مصنع المروة العمراوي لزخرفة الزجاج و الكريستال** — جراح، أجا، الدقهلية.
جملة · قطاعي · إستيراد أدوات منزلية.

مبني من الـ **El Marwa Glass Design System** (نسخة المتجر رقم 3).

## التشغيل محلياً

```bash
npm install
npm run dev      # سيرفر تطوير
npm run build    # بناء للإنتاج في dist/
npm run preview  # معاينة نسخة الإنتاج
```

## بنية المشروع

```
index.html            صفحة الدخول + خطوط Google + وسوم SEO
src/main.jsx          يحمّل الـ design system bundle وبيانات المتجر ثم يشغّل التطبيق
src/bootstrap.jsx     ترتيب تحميل شاشات المتجر
src/App.jsx           التوجيه (routing) وحالة السلة
src/app/*.jsx         شاشات المتجر: الهيدر، الرئيسية، القوائم، المنتج، السلة، الدفع، الصفحات، أدوات الـ CRO
src/vendor/           _ds_bundle.js (مكوّنات الديزاين سيستم) + data.js (المنتجات والأقسام)
src/styles/           styles.css + tokens (ألوان، خطوط، مسافات، ظلال، حركة)
public/assets/        صور المنتجات واللوجو والخلفيات
public/icons/         أيقونات lucide محلية (بدل التحميل من CDN)
```

## النشر

منشور على Vercel — كل push على الفرع `main` بينشر أوتوماتيك.

## ملاحظات قبل الإطلاق الحقيقي

- **صور المنتجات** حالياً بمقاس إنستجرام (206×206) — محتاجة إعادة تصوير/تصدير بمقاس 1200px+ لصفحة المنتج والبانرات.
- **الأسعار أرقام مبدئية** وليست أسعار المحل الحقيقية.
- **السلة والدفع تجريبيان** — مفيش بوابة دفع أو باك-إند متوصّلين لسه.
- الخطوط بدائل من Google Fonts (Cinzel · Jost · Tajawal · Cairo · Amiri) لأن خطوط اللوجو الأصلية مرسومة يدوياً.
- كوبونات وعروض (FIRST10، شحن مجاني فوق 3000، خصومات الباقات) لازم تتأكد منها قبل الإطلاق.
